# Узел связи

Резка решает, что отдать, по стране, из которой пришёл запрос. Из Италии она отдаёт всё, из
Израиля — заставку про подписку под всеми пятью подписями качества. Из кода это не лечится:
решение принимается до того, как наш код что-либо получит.

Узел — это маленький передатчик: телефон обращается к нему, он обращается к резке, и для резки
запрос приходит ОТТУДА, ГДЕ СТОИТ УЗЕЛ. Поэтому важно только одно — где он стоит.

Зависимостей нет, ставить ничего не нужно, нужен только Node.

## Где его ставить

**Правильно — на европейской машине.** Тогда `host` в `tools/relay.config.json` оставляется
пустым, и узел выходит собой, напрямую. Никакой прокси не нужен.

**На своём компьютере** он имеет смысл, только если в конфиге прописан живой SOCKS5 в нужной
стране: тогда узел одалживает его точку выхода. Проверить прокси: `node tools/checkproxy.js`.

Cloudflare (`cloudflared tunnel`) точку выхода НЕ меняет — он лишь открывает наружу то, что
крутится на вашей машине. Нужен, только если узел стоит дома, а подключаться к нему надо с улицы
или другому человеку.

## Запуск

    node tools/relay.js

Скрипт печатает готовый адрес вместе с ключом. Он вписывается в приложении:
Настройки → Узел связи. Там же переключатель «Видео через узел» / «Видео напрямую»: право на
качество резка решает в момент выдачи ссылки, поэтому раздача по готовой ссылке страну может уже
не проверять — тогда через узел идёт только переписка, а фильм качается напрямую.

## На европейской машине, по шагам

Годится любая: Oracle Cloud (бесплатная навсегда, регион Франкфурт или Амстердам), Hetzner,
Aeza — от трёх евро в месяц.

1. Поставить Node:            `sudo apt update && sudo apt install -y nodejs`
2. Скопировать туда два файла: `tools/relay.js` и `tools/relay.config.json`
3. В конфиге очистить `host` (оставить `""`) — узел будет выходить сам
4. Открыть порт 8099 в брандмауэре машины и в панели провайдера
5. Запустить, чтобы жил после выхода:   `nohup node relay.js > relay.log 2>&1 &`
6. Взять из вывода адрес с ключом и вписать в приложении

Адрес постоянный, компьютер дома выключать можно, Владу делать ничего не надо.

## Ключ

Узел, открытый наружу, — это вход в резку для всего интернета. Поэтому в пути обязателен ключ
(он в пути, а не в заголовке: через узел ходит и плеер, а ему заголовки не пропишешь).
Ключ лежит в `tools/relay.config.json`. Чтобы отозвать доступ — вписать новый и перезапустить.

## Приложение для тех, кто не в вашей сети

## Установка на европейскую машину — одной вставкой

Зайти по ssh и вставить целиком:

```sh
sudo apt update && sudo apt install -y nodejs
mkdir -p ~/relay && cd ~/relay
cat > relay.config.json <<'EOF'
{"host":"","port":0,"user":"","pass":"","key":"MgkLobCyNviyY37q-WoWUjq3"}
EOF
# сюда же скопировать relay.js (scp с компьютера, см. выше)
sudo iptables -I INPUT -p tcp --dport 8099 -j ACCEPT
nohup node relay.js > relay.log 2>&1 &
sleep 1 && cat relay.log
```

Пустой `host` означает «выходить напрямую с этой машины» — прокси не нужен, страну даёт сам сервер.
Последняя строка напечатает готовый адрес с ключом: его и вписать в Настройки → Узел связи.

Чтобы узел поднимался после перезагрузки:

```sh
(crontab -l 2>/dev/null; echo "@reboot cd ~/relay && node relay.js >> relay.log 2>&1") | crontab -
```
