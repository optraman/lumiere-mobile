# Как получить Люмьер на iPhone — по шагам

iOS-приложение собирается только на Mac, поэтому сборку делает бесплатная macOS-машина GitHub
(`.github/workflows/ios-ipa.yml`). На выходе — `Lumiere.ipa` без подписи; подпись ставит
программа, которой он устанавливается.

## Часть 1. Выложить проект на GitHub (один раз)

1. Зарегистрироваться на github.com (если аккаунта нет).
2. Скачать и поставить GitHub Desktop (desktop.github.com), при первом запуске — Sign in to GitHub.com.
3. File → Add local repository… → Choose… → папка `Desktop\lumiere-mobile` → Выбор папки.
4. Появится «This directory does not appear to be a Git repository» — нажать ссылку
   **create a repository** в этом сообщении.
5. В окне Create a new repository: Name — `lumiere-mobile`, Git ignore — None (свой уже есть),
   остальное не трогать → **Create repository**.
6. Сверху синяя кнопка **Publish repository** → галочка **Keep this code private** должна стоять
   (в коде лежат ключи) → **Publish repository**.
   Папки `node_modules`, `.expo` и файл `.env` не выгружаются — так и должно быть.

## Часть 2. Ключи (один раз)

1. Открыть в Блокноте файл `.env` в папке проекта. Там две строки вида `ИМЯ=значение`.
2. На github.com открыть свой репозиторий → вкладка **Settings** (сверху справа) →
   слева **Secrets and variables** → **Actions** → зелёная **New repository secret**.
3. Name: `TMDB_API_KEY`, Secret: всё, что после `EXPO_PUBLIC_TMDB_API_KEY=` (без пробелов и
   кавычек) → **Add secret**.
4. Ещё раз New repository secret: Name `WYZIE_KEY`, Secret — всё после `EXPO_PUBLIC_WYZIE_KEY=`.

## Часть 2½. Патчи по воздуху — Expo (один раз, ДО первой сборки)

1. Зарегистрироваться на expo.dev.
2. Нажать на свой аватар/имя → **Account settings** → слева **Access tokens** →
   **Create token**, имя любое → скопировать (показывается один раз).
3. В GitHub новый секрет: Name `EXPO_TOKEN`, Secret — этот токен.

Проект на expo.dev и его ID искать не нужно: сборка сама находит (или создаёт) проект
`lumiere-mobile` по токену и пишет его ID в журнал шага «Проект Expo».

## Часть 3. Сборка

1. В репозитории вкладка **Actions**. Слева — «Сборка .ipa», нажать.
2. Справа серая кнопка **Run workflow** → в выпадашке ветка `main` → зелёная **Run workflow**.
3. Через пару секунд появится строка с жёлтым кружком — идёт сборка (около 30 минут).
   Зелёная галочка — готово, красный крестик — ошибка.
4. Нажать на строку запуска → внизу страницы раздел **Artifacts** → `Lumiere-ipa`.
   Скачается `Lumiere-ipa.zip`, внутри — `Lumiere.ipa`. Распаковать.
5. Если крестик — там же будет `build-log`: скачать и прислать.

## Часть 3½. Патч (обычное обновление)

1. GitHub Desktop → внизу слева в Summary написать, что поменялось → **Commit to main** →
   сверху **Push origin**.
2. github.com → Actions → слева **«Патч»** → Run workflow → в поле можно написать, что в патче →
   Run workflow. Идёт пару минут.
3. На телефоне: открыть «Люмьер» — патч скачается в фоне. Закрыть приложение совсем (смахнуть
   из переключателя) и открыть снова — уже новая версия.

Патчем доходит всё, что в коде: экраны, плеер, источники, анимации, тексты, картинки.
**Не доходит** нативная часть — новый нативный модуль, иконка, название, разрешения в app.json.
Тогда: в `app.json` поднять `version` (1.0.0 → 1.1.0) и `ios.buildNumber`, собрать новый .ipa
(Часть 3) и поставить поверх. Старые установки патчи для новой версии не получат — так и задумано,
иначе они бы на них падали.

## Часть 4. Установка — Sideloadly (с компьютера по кабелю)

1. Поставить iTunes и iCloud **с сайта Apple**, не из Microsoft Store (Sideloadly с версиями из
   Store не видит телефон).
2. Скачать Sideloadly с sideloadly.io, установить.
3. Подключить iPhone кабелем, разблокировать, на «Доверять этому компьютеру?» — Доверять.
4. Sideloadly: перетащить `Lumiere.ipa` в окно (иконка IPA слева), в iDevice выбрать телефон,
   в Apple account вписать свой Apple ID → **Start**. Пароль и код из SMS/с другого устройства
   вводятся в окне Sideloadly. Можно завести отдельный Apple ID специально для этого.
5. На iPhone: Настройки → Основные → VPN и управление устройством → строка с твоим Apple ID →
   Доверять.
6. Настройки → Конфиденциальность и безопасность → Режим разработчика → включить →
   перезагрузка → после неё подтвердить «Включить».
7. Запускать «Люмьер».

Бесплатная подпись живёт 7 дней: потом приложение перестаёт открываться. Повторить пункт 4 с тем
же файлом — приложение переустановится поверх, история, «Моё» и загрузки сохранятся.
Ограничения бесплатного Apple ID: не больше 3 таких приложений на телефоне.

## Другие способы установки того же .ipa

- **TrollStore** — без Apple ID и без 7 дней, навсегда. Работает только на iOS 14.0–16.6.1,
  16.7 RC и 17.0 (версия: Настройки → Основные → Об этом устройстве). Инструкция — ios.cfw.guide.
- **ESign / Feather / Scarlet и подобные** — ставят .ipa прямо с телефона, но им нужен
  сертификат. Общие бесплатные сертификаты Apple регулярно отзывает — приложение в такой день
  перестаёт запускаться до переподписи.
